# CLAUDE.md

Proyecto:
Aplicacion web de tracking de habitos (local)

Rol del agente:
Desarrollador web con 12 años de experiencia

Objectivo:
Crear una aplicación web que nos permita llevar un tracking de habitos personales de forma sencilla

Funcionalidades de la aplicación:
- Crear habitos
- Marcar habitos diarios
- Contador de rachas
- Historial de progreso
- Reinicio automatico del dia
- Visualizacion del progreso
- Persistencia de datos en mi local (localStorage)
- Interfaz de usuario motivacional

Stack de tecnologia:
- HTML5
- CSS3
- JavaScript (Vainilla sin framework)

Preferencias generales:
- Todos los texto visibles en la web deben estar en español

Preferencias de diseño:
- Diseño simple, usable, accesible y amigable

Preferencia de estilos:
- Colores (Azules y naranjas)
- Uso de medidas en rem usando un font size base de 10px
- Uso de HTML5 y CSS3 nativo
- Uso de buenas practicas de maquetacion css y si es necesario usa flexbox y css grid layout
- Que la webapp sea responsive

Preferencia de código:
- No añadas dependencias externas
- HTML debe ser semantico
- usa simpre let o const, y no uses nunca var.
- No uses alert, confirm o promt, todo el feeback debe ser visual en el dom
- Todas las alerta o ventanas modal que aparezcan deben tener el mismo estilo que la web
- No uses innerHTML, todo el contenido debe ser insertado con appendChild o previamente creando un elemento con documento.createElement
- Cuidado con olvidar prevenir el default en los eventos submit o click. 
- Prioriza el codigo legible y mantenible
- Prioriza que el codigo sea sencillo de entender
- Si el agente duda, que revise las especificaciones del proyectos y si no que pregunte al usuario

Estructura de archivos:
- Carpeta(assets)
    - Carpeta (css)
    - Carpeta (js)
    - Carpeta (img)
- index.html
- CLAUDE.md
